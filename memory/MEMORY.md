# Pengeprat – Prosjektminne

Se `CLAUDE.md` i rota og dokumentasjonen i `docs/`:

- `docs/produkt.md` — prinsipper, stegene, beregningsregler
- `docs/arkitektur.md` — oppbygning, lagring, testing

Aktiv kode ligger i `src/` (Astro + React). Mappene `pengeprat/` og
`uventet-sum/` og `index.html`/`style.css` i rota er en gammel vanilla-versjon
som ikke lenger brukes.
